# 🚲 서울시 공공자전거 데이터 분석 (Seoul Bike Rental Data Analysis)

## 📌 프로젝트 개요
서울시 공공자전거(따릉이) 대여 데이터를 분석하여 시간대, 요일, 구별, 대여소별 이용 패턴을 파악하고, 시각화를 통해 사용자 행동에 대한 인사이트를 도출하는 프로젝트입니다.

---

## 🛠️ 사용 기술 및 도구

- Python
  - `pandas`, `numpy`: 데이터 처리
  - `matplotlib`, `seaborn`: 데이터 시각화
  - `folium`: 지도 기반 시각화
- Jupyter Notebook
- 데이터 출처:
  - 서울 열린데이터 광장
  - 서울시 공공자전거 대여소 정보
  - 행정구역 GeoJSON

---

## 📁 주요 작업

### ✅ 데이터 전처리
- 여러 개의 월별 대여 CSV 병합
- 날짜 기반 파생 변수 생성: `요일`, `시간대`, `주말여부`
- 대여소 위치 정보 병합 (위도/경도, 행정구역 포함)

### ✅ 탐색적 데이터 분석
- 시간대별, 요일별 대여 패턴 분석
- 주말과 평일 간의 차이 분석
- 구별 평균 이용 시간 계산 및 시각화

### ✅ 시각화
- `seaborn` 히트맵: 요일-시간대, 구-시간대
- `folium` 지도:
  - 평균 이용 시간에 따른 구별 색상 시각화
  - 주말 대여 건수 기준 대여소 마커 표시

---

## 📊 분석 인사이트

- 주말에 대여량이 급증하는 대여소들은 주로 관광지 인근에 분포
- 강남, 용산, 송파 등은 평균 이용 시간이 길고, 회귀 수요가 높은 지역으로 추정
- 평일 출근시간(7–9시), 퇴근시간(17–20시)에는 중심업무지구의 수요 증가
